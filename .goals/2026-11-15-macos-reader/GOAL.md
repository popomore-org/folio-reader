# Folio macOS 阅读器

实现本地阅读优先的 macOS 应用和可供 Mokisu 等 Rust 宿主调用的库。通过 Finder 或打开面板选择文件或目录，浏览目录、阅读和切换内容；支持 Markdown、纯文本/源码、RTF、HTML、PDF、静态图片、音视频、CSV/TSV、Mermaid 与 Vega-Lite。支持跳转目录内链接、文档大纲、专注阅读、统一窗口外观和小幅编辑 UTF-8 Markdown/文本。

- SVG 文件使用只读图片预览。Markdown 按工作区图片规则显示相对路径引用的 SVG。
- 文件更改由用户确认保存，外部更改有冲突提示，切换和退出会保护草稿。
- Git 工作区提供当前文件工作区状态、提交列表和补丁预览。普通目录仍可完整使用阅读功能。
- Rust 核心独立于 UI，需通过独立 Cargo 消费样例。预览不执行用户脚本。
- 对照 Meta a3a966614c0ccd31f4b2255808172390266b1d4f 及同类产品研究记录。验收源码检查、真实 macOS 运行和 PR 当前检查。
- 本地 ad hoc 预览与正式签名、公证、更新分发分属不同交付。合并和公开发布需单独授权。

## 2026-11-15 界面增补

- 多目录由侧栏添加、移除并跨启动保存。目录树按文件类型显示单色图标，导航统一底色，移除顶部文件夹按钮。
- 原生设置负责阅读外观。文件可使用系统提供的应用列表或手动挑选应用打开。
- 标签页和可合并的左右两栏可同时打开不同文件。切换时保留草稿，关闭时复用保存冲突处理。
- 标签页支持同栏拖动排序和跨栏拖动。可拖到另一栏的标签之间或空白阅读区，移动时保留源码模式和未保存草稿。
- 单栏中把标签拖到阅读区右边缘时建立右栏。可编辑文件支持同一标签内的源码／实时预览分栏，预览读取当前草稿，保存后保持分栏。
- 左右分栏标签条顶部对齐，创建空栏或关闭最后一个标签时仍保持位置。
- 从侧栏或外部打开文件时复用同一工作区窗口，保持窗口位置、尺寸和侧栏标题高度。冷启动直接打开文件时只呈现一个工作区窗口。
- 底栏左侧放目录和 Git 入口，右侧放文档状态、分栏和大纲。独立 Git 视图展示目录范围内的工作树变更、当前文件历史和可读补丁。
- Open As 放在各个文件路径行右端，文档查找和保存可通过 ⌘F、⌘S 操作。
- 交付前复核较早参考的阅读器界面和文件图标方案，并在应用、Rust 与 CI 入口验证。

## Zed 交互与视觉调整

- 以本机 Zed 1.28.1 的表面、分隔线、密度和活动提示为参考，正文和工作区共用浅色或深色外观。
- 文件与标签切换自动定位侧栏，支持从键盘聚焦、移动、展开和打开；标签条提供针对分栏的操作与路径。
- 目录树名称和标签使用 13 pt，文件路径和底栏状态使用 12 pt。浅色次要文字使用 `#646D79`，Markdown 正文默认 18 px。
- 底栏进入 Git，文件历史以列布局展示，补丁保持足够宽度。

- 正式包内置自动检查、下载与安装的独立控制。手动入口显示版本、发行说明、进度和错误。编辑、媒体和打开面板活动结束后才允许更新重启。

## Finder 快速查看

- 在 Finder 选中 UTF-8 `.md` 或 `.markdown`，按空格显示 Folio 排版的只读预览。以没有运行 Folio 主窗口的状态验收，覆盖标题、表格、任务清单和代码块。
- 扩展随预览、更新测试及正式应用打包，按应用身份分别签名。复用 Markdown 渲染，读取上限 2 MiB，禁止加载外部资源和运行用户脚本。
